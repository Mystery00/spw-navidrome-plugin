# Tag 自动发布计划

目标：推送严格的 `v主版本.次版本.修订版本` tag 后，在无 SPW 安装的 Windows runner 上构建并发布 `.spmod`。README 不固定插件版本，不重复链接自身仓库。

1. 为 tag 校验添加回归，拒绝前导零、预发布标记、换行及非法输入。
2. 增加独立构建模式，使用官方公开 API dev23 编译；沿用现有打包校验，本地宿主测试路径保持可用。
3. 配置只读构建与独立发布任务，版本取自 tag，先上传草稿附件再公开 Release；使用固定提交的官方 Actions。
4. 更新下载和维护说明。Steam 条目尚未发布，明确标注待发布。
5. 实际运行独立构建、检查产物版本与依赖隔离、审查 workflow；不创建测试 tag 或公开 Release。

验证边界：CI 的公开 API 编译和回归不能代替 SPW 实机 UI、播放及私有宿主 ABI 验证。
