# SPW 原生页面与凭据迁移实施计划

> 执行：使用 subagent-driven-development 分任务实施并独立审查；用户已授权自主开发。

**目标：** 在 SPW 1.19.x 内完成登录、专辑/歌单浏览、搜索和选曲，移除独立 Swing 窗口；通过 Windows 当前用户 DPAPI 保存密码并恢复登录。

**架构：** 保留 Subsonic、缓存、回环流和 AppSession，新增独立凭据存储及界面状态层。Kotlin Compose 页面通过官方 UI Hook 挂载到本插件配置路由；宿主 ABI 以实际安装版本校验。

**技术：** Java、Kotlin Compose、SPW Workshop API、Windows DPAPI。基线提交 fe4bd3e。

## 全局约束

- 用户明确选择 1.19.x 和 Windows 加密保存密码；不把密码写入普通配置、命令行或日志。
- 中文文案、注释、文档；英文日志；Windows 命令 tty:true。
- 只替换自己的插件页面，不影响其他模组；不使用独立窗口替代内嵌页面。
- 保留实际原生播放、封面、歌词；旧版本不假装兼容。
- 本地测试只使用合成凭据，真实密码仍由用户在界面输入。

## 审查重点

凭据损坏和解密失败、保存失败时保留旧文件、退出后旧请求回填、页面卸载清理、宿主升级后的 ABI 不兼容。

### Task 1: Windows 凭据存储

文件：新增 credentials/CredentialStore.java、credentials/WindowsProtector.java 和 CredentialStoreTest.java。暂不改 AppSession、入口和构建器。

接口：CredentialStore(Path directory)，save(String address,String username,char[] password,boolean allowHttp)，load() 返回 Optional<SavedLogin>，clear()；SavedLogin 暴露 address()/username()/password()/allowHttp()，实现 AutoCloseable 并清空内部密码。存储实现线程安全。

- [x] 先写失败测试：中文和特殊字符往返，磁盘无明文密码，重新构造存储恢复，损坏密文失败且无泄露，清除后为空。
- [x] 用 Windows 用户级 DPAPI 实现，禁止任何明文降级。复用宿主 JNA 直接调用 Crypt32Util，使用 UI_FORBIDDEN 和当前用户范围，不启动外部进程。使用 JSON 保存地址、账号、HTTP 选择、密文版本和 Base64 密文；整份登录载荷加密以避免身份与密文错配。
- [x] 写入同目录临时文件后原子替换；加载限制大小，保存失败保留旧文件；不解密加载真实用户现有凭据。
- [x] 测试真实 DPAPI，并添加可注入 protector 以测试失败保留旧文件；独立编译测试，完整测试报告交主代理。
